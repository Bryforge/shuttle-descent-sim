# shuttle-descent-sim
Hi, SpaceX!

Shuttle Descent Simulation is a React-based visual flight model that demonstrates an unpowered shuttle-style descent after separation, where thrust is disabled and mass remains constant. It simulates the vehicle’s trajectory under gravity, lift, drag, bank angle, atmospheric density, dynamic pressure, and load constraints, allowing users to adjust flight parameters and see how they affect descent behavior, admissible trajectory conditions, and landing-state performance.
