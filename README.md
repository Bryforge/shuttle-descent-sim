# Shuttle Descent Simulation

A React/Vite visual simulation of an unpowered shuttle-style descent after separation.

The model demonstrates:

- T = 0 unpowered descent
- m_dot = 0 constant mass
- gravity, lift, and drag effects
- bank angle control
- dynamic pressure constraints
- load factor constraints
- trajectory visualization
- altitude/range and pressure charts

This is an educational aerospace simulation and visualization, not certified flight software.
